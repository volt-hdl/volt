# ADR-0026: Üretilen Kodun Dili — Her Zaman İngilizce

> Statü: KABUL EDİLDİ
> Tarih: 2026-09-08
> Etkilenen: sv-mapping.md §12, volt-sv-emit, tests/fixtures/counter.expected.sv
> Uygulama aşaması: F4 sonu

## Sorun

`volt build` çıktısındaki dosya başlığı ve üretici yorumları Türkçeydi:

```systemverilog
// Bu dosya Volt tarafından otomatik üretilmiştir.
// Kaynak: counter.volt
// Volt sürümü: 0.1.0
//
// DÜZENLEMEYİN — değişiklikler kaynak dosyada yapılmalıdır.
```

Tanı mesajları `--lang en|tr` ile kullanıcının diline uyarlanıyor
(cli-contract.md); üretilen SV'nin de aynı mekanizmaya bağlanıp
bağlanmayacağı tanımsızdı. Türkçe başlık, İngilizce dokümantasyonlu bir
projede üretilen artifakta sızıyor ve README'de "the header comments are
emitted in Turkish today" gibi açıklamalar gerektiriyordu.

## Seçenekler

**Seçenek A — Üretilen kod `--lang`'i izlesin**
Başlık yorumları tanı diliyle birlikte değişir. Ancak üretilen SV bir
kullanıcı mesajı değil, kod artifaktıdır: sürüm kontrolüne girer, CI
loglarında diff'lenir, takım üyeleri ve harici araçlar (lint, formal,
sentez raporları) tarafından okunur. Aynı kaynağın iki makinede farklı
byte üretmesi determinizmi (sv-mapping.md §12 "deterministik başlık")
ve snapshot testlerini bozar.

**Seçenek B — Üretilen kod her zaman İngilizce**
Başlık ve tüm üretici yorumları sabit İngilizcedir; `--lang` yalnız
tanı/açıklama metinlerini etkiler. Kaynak dosyadaki `///` doc yorumları
ne yazılmışsa aynen taşınır (çeviri yapılmaz — kullanıcının metnidir).

**Seçenek C — Başlıktan yorumları tamamen çıkar**
Dil sorunu kalkar ama üretilmiş-dosya uyarısı ("DO NOT EDIT") ve kaynak
izlenebilirliği kaybolur; endüstri geleneğine (üreteç damgası) aykırı.

## Karar: Seçenek B — Üretilen Kod Her Zaman İngilizce

Üretilen SV/SVA/SBY dosyalarındaki tüm üretici metinleri sabit
İngilizcedir ve `--lang`'den etkilenmez:

```systemverilog
// This file was generated by Volt.
// Source:  counter.volt
// Version: 0.1.0
//
// DO NOT EDIT — make changes in the source file instead.
```

Gerekçe:

- **Kod artifaktı ≠ kullanıcı mesajı.** Tanılar okuyana göre değişebilir;
  üretilen kod depoya girer ve dil tercihi olmayan araçlarca işlenir.
  Donanım ekosisteminin ortak dili İngilizcedir.
- **Determinizm.** Aynı kaynak her ortamda byte-aynı çıktı üretir;
  `counter.expected.sv` snapshot testi tek bir doğru çıktıya bağlanabilir.
- **Diff hijyeni.** `VOLT_LANG` farkı yüzünden üretilmiş dosyalarda sahte
  diff oluşmaz.
- Kullanıcının kendi `///` doc yorumları hangi dilde yazıldıysa o dilde
  taşınmaya devam eder — üreteç kullanıcı metnine dokunmaz.

Türkçe tanı mesajları (`messages/tr.rs`, `explain/tr.rs`) bu karardan
etkilenmez; `--lang=tr` davranışı aynen sürer.

## Sonuçlar

- **volt-sv-emit `header()`**: başlık şablonu İngilizceye çevrildi;
  `--lang` parametresi almaz.
- **tests/fixtures/counter.expected.sv**: yeni başlıkla yeniden üretildi
  (elle yazılmadı, `volt build` çıktısından kopyalandı).
- **tests/fixtures/counter.volt** ve `tests/ui/` fixture yorumları
  İngilizceye çevrildi — golden dosyalar artifakt zincirinin parçasıdır
  ve README'de sergilenir.
- **sv-mapping.md §12**: başlık örneği bu ADR'deki İngilizce biçimi
  yansıtacak şekilde bir sonraki spec revizyonunda güncellenmelidir
  (spec salt okunur olduğundan bu ADR kayıt görevi görür).

## Emsal

Üreteç damgasını sabit İngilizce basmak yaygın gelenek: `protoc`
("Generated by the protocol buffer compiler. DO NOT EDIT!"), Rust
`bindgen`, `go generate` çıktıları ve Verilator'ün kendi üretilmiş
başlıkları yerelleştirilmez. Yerelleştirme kullanıcıya dönük akışlarda
(tanı, yardım metni) kalır.
